# Security Policy

## Supported Versions

Only the latest `main` branch deployment is actively supported with security updates.

| Version | Supported |
| --- | --- |
| `0.1.x` (`main`) | Yes |

## Architecture Note

This project is a static and server-rendered Next.js site with **no user accounts, no database, no API keys, no cookies, and no third-party tracking scripts**.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, use **[GitHub Private Vulnerability Reporting](https://github.com/Poorna-bot/salalihini-sandeshaya/security/advisories/new)** on this repository to submit a report privately to the maintainer. We will acknowledge receipt within 7 days and publish a fix as quickly as possible.
